Bringing Minecraft Live Events Back to Life

Minecraft Live Event Recreations is an upcoming organization of developers working on bringing back past live event servers that Mojang Studios produced along with other creators.

How can I contribute?

Contributing can be as simple as playing! Screen record yourself playing an active live event and post it in our Discord server under the videos channel. We use videos to help gather data to use for recreating the same server behaviors.

Want to help us further? Come volunteer! See our volunteer jobs page for more information.


For more information about Minecraft live event servers, check out the Minecraft Wiki!
